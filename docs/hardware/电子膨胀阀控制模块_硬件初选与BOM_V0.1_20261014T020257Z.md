## 1. 选型结论

选型已经开始。优先建立**双极阀无传感器端止/堵转验证平台**，并同时设计单极恒流/检测验证板；检测和阀接触安全通过后，再冻结统一PCB。

推荐结构：ESP32-S31应用主控 + STM32G0B1系列通信MCU + 双极TMC2240候选 + 单极四路恒流功率级 + 同步电气测量。保留CAN FD、LIN从节点、UART、USB以及Wi-Fi本地控制台/OTA。

本轮官方资料联网获取未完成，以下是工程候选，不宣称已对最新规格、库存/价格和生命周期完成在线核验，也不构成采购清单。准确封装/后缀及数量按原理图复核。无法验证的能力明确保留门槛，尤其没有零位传感器时，堵转识别不等价于绝对端点测量。

## 3. 集成度取舍

CAN FD、LIN、UART集中到一颗通信MCU，满足三种协议并行处理的目标；CAN FD和LIN仍各有物理收发器。MCP2518FD保留为只需独立CAN FD时的备选，本轮不作为集中三接口的首选。

双极优先专用步进芯片。5线单极公共端不能直接套用TMC2240双H桥接法；本轮未核验到一颗能直接满足公共端四相恒流、256细分及可靠无传感器端点识别的器件，因此采用混合硬件方案作为验证基线。若要求单极也必须单芯片且全部功能成立，需要把此条件作为供应商选型门槛，现阶段不能承诺已找到合适芯片。

## 4. 选型优先级与试验顺序

1. **主控资料与SDK**：核对ESP32-S31官方型号/模块与MicroPython/OTA移植能力；这是主板冻结前置项。
2. **双极诊断可行性**：TMC2240评估板连接已知260 mA、24.3 Ω定子，测量允许速度下的正常运动、全关、全开、半程卡滞、重复卡滞；先确认诊断窗口。
3. **阀端止安全**：确定阀允许的端止接触、退让/复探次数及全开有效范围。不能只测电机堵转而不验证阀座/传动寿命。
4. **单极恒流/诊断**：取得单极接线、电流/R/L后，单相板验证限流、衰减、采样，扩到四相；闭环诊断所需ADC由采样预算决定。
5. **通信芯片并发**：STM32G0B1候选平台同时运行CAN FD、LIN从节点和外部UART，并验证SPI链路/本地LIN响应与心跳。
6. **电源与统一板**：最坏单电机、Wi-Fi峰值、两MCU和诊断ADC同时工作；验证欠压、回灌、温升与互锁，之后冻结原理图/BOM。

本轮未执行电机/阀样机试验，未跑固件验证或板级测试；设计文档格式检查不等于器件功能验证。

## 5. 固定电气预算与待确认项

已知双极：260 mA、24.3 Ω/相，单相直流压降约6.318 V，单相260 mA持续铜耗约1.643 W。260 mA暂作为峰值上限，不未经确认转换为260 mA RMS。

仍缺：单极额定电流/接线/R/L、阀允许频率与最大压差、真实端点接触规范、机械有效全开与端止关系、输入源浪涌/环境、ESP32-S31具体模块资料。用户可自由配置步数，但无传感器端点算法仍必须针对实际阀特性验证。

电源按单电机最坏工况加逻辑/诊断预算，暂不承诺最终最大相电流、板面积和总成本。采样电阻值、TVS/钳位、电感与散热须从实际负载和波形计算。
