# EXV Controller

基于ESP32-S31的电子膨胀阀控制模块。

支持单极/双极爪极定子（单次使用一种）、恒流及最高256细分、9–24 V输入、CAN FD/LIN/UART/USB，以及Wi-Fi网页控制、可视化和网页上传OTA。阀控制包括回零、步数/开度控制、堵转报警及自动行程识别。
